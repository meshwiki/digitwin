Volunteers wanted for the MeshCore Digital Twin project

We are starting a project to build a digital twin of the MeshCore network in the Netherlands. The goal is to simulate the real mesh network using observed message propagation data from the MC Radar observer network.

With this model we want to better understand how messages move through the network and experiment with repeater configurations, routing behavior, and resilience without affecting the live network.

The project will likely involve a mix of:
• network modeling and simulation
• data analysis of observer logs
• experimentation with message propagation models
• possibly building tools to visualize and test the network

If you are interested in contributing, please send me a DM with a short message including:

• your background (technical or otherwise)
• any relevant skills (programming, networking, RF, graph theory, data science, simulation, etc.)
• how much time you might realistically contribute
• your motivation for joining the project

You do not need to be an expert. Curiosity and willingness to experiment are just as valuable.

Once we have a small group together we will coordinate development and discuss the technical approach.

There is a primer available on https://github.com/meshwiki/digitwin
